# The Halloween Commit: Horror at the Server Room

## Presentació i entorn

**Autor:** Joan Coll Serrat

Aquesta pràctica simula la recuperació d'un repositori afectat
per un commit defectuós. S'hi treballen la creació d'un repositori
local, els commits, les branques, la resolució manual d'un
conflicte i la restauració d'un estat segur.

El projecte s'ha desenvolupat a Windows, utilitzant PowerShell
des de Visual Studio Code. El fitxer principal és Main.java,
escrit en Java, i la branca principal s'anomena master.
